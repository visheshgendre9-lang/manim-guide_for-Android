03 Making an Animation (Every Time)

Follow these steps every time you open Termux and want to create or render an animation.

⚡ Quick copy-paste: run this one block to login, go to your project folder, and activate Manim — all in one go. Then jump straight to Step 3 to create your file.
Termux — login + activate (copy this whole block) 
proot-distro login ubuntu --shared-tmp -- bash -c "cd ~/manim-projects && source manim-env/bin/activate && bash"

This logs into Ubuntu, moves into your project folder, and activates Manim automatically. You'll see (manim-env) appear at the start of your prompt — you're ready to create your file.

Step 1 — Open Termux & Enter Ubuntu

Termux 
proot-distro login ubuntu

Your prompt changes to root@localhost:~#. You are now inside Ubuntu.

Step 2 — Go to Your Project Folder & Activate Manim

Ubuntu 
cd ~/manim-projects
source manim-env/bin/activate

You'll see (manim-env) appear at the start of your prompt. Manim is now ready.

Step 3 — Create or Edit Your Animation File

Create a new file or edit an existing one using nano:

Ubuntu — create new file 
nano my_animation.py

Write your animation inside. Here is a full example with the most common elements:

Python — my_animation.py 
from manim import *

class MyScene(Scene):
    def construct(self):

        # ── Text ──────────────────────────────────
        title = Text("Hello, Manim!", font_size=48)
        self.play(Write(title))
        self.wait(1)
        self.play(FadeOut(title))

        # ── Shapes ────────────────────────────────
        circle = Circle(radius=1.5, color=BLUE)
        square = Square(side_length=2, color=RED)
        square.next_to(circle, RIGHT, buff=0.5)

        self.play(Create(circle), Create(square))
        self.wait(1)

        # ── Move a shape ──────────────────────────
        self.play(circle.animate.shift(UP * 2))
        self.wait(0.5)

        # ── Change color ──────────────────────────
        self.play(circle.animate.set_color(GREEN))
        self.wait(0.5)

        # ── Math equation ─────────────────────────
        eq = MathTex(r"e^{i\pi} + 1 = 0", font_size=56)
        self.play(FadeOut(circle), FadeOut(square))
        self.play(Write(eq))
        self.wait(2)

        # ── End ───────────────────────────────────
        self.play(FadeOut(eq))

When done writing, save and exit nano: press Ctrl+X → Y → Enter.

ℹ️
Common things you can use:
Text("...") — plain text  |  MathTex(r"...") — math equations
Circle() Square() Triangle() Arrow() Line() — shapes
Write() — draw text/equations  |  Create() — draw shapes
FadeIn() FadeOut() — appear/disappear
.animate.shift() .animate.scale() .animate.rotate() — move/transform
self.wait(1) — pause for 1 second

Step 4 — Render the Animation

Choose a quality level. Always start with low quality to test, then switch to high for the final version.

Ubuntu — render commands 
# Low quality — 480p, fastest (use for testing)
manim -ql my_animation.py MyScene

# Medium quality — 720p
manim -qm my_animation.py MyScene

# High quality — 1080p (slow, use for final render)
manim -qh my_animation.py MyScene

# 4K quality — 2160p (very slow, only for powerful devices)
manim -qk my_animation.py MyScene
⚠️
Replace MyScene with whatever you named your class. In the example above it's MyScene. It must match exactly.

Step 5 — Find & Copy the Output Video

After rendering, Manim saves the video here:

Ubuntu — output path 
# Low quality output path
~/manim-projects/media/videos/my_animation/480p15/MyScene.mp4

# Copy to Downloads so VLC can open it
cp ~/manim-projects/media/videos/my_animation/480p15/MyScene.mp4 /sdcard/Download/

Open VLC on your tablet → tap Browse → Downloads → tap the file.

Step 6 — Making Another Animation

Just repeat from Step 3. Create a new .py file with a new class name, or add a new class to the same file and render it by name.

🚀

Method B — Command Line Flags (Quick Override)

Add flags directly to your render command without editing any file. These override the config file.

Ubuntu — all available flags 
# Quality presets
manim -ql file.py Scene   # 480p  15fps — fastest
manim -qm file.py Scene   # 720p  30fps
manim -qh file.py Scene   # 1080p 60fps
manim -qp file.py Scene   # 1440p 60fps — production
manim -qk file.py Scene   # 2160p 60fps — 4K (very slow)

# Custom resolution & FPS
manim -ql --resolution 1280,720 --frame_rate 60 file.py Scene

# Background color
manim -ql --background_color WHITE file.py Scene
manim -ql --background_color "#1a1a2e" file.py Scene

# Save as GIF instead of MP4
manim -ql --format gif file.py Scene

# Save last frame as PNG image
manim -ql --save_last_frame file.py Scene

# Transparent background (saves as webm)
manim -ql --format webm --background_opacity 0 file.py Scene

# Skip to a specific animation number
manim -ql -n 3 file.py Scene

# Render only animations 3 to 7
manim -ql -n 3,7 file.py Scene

# Disable cache (force full re-render)
manim -ql --disable_caching file.py Scene

# Preview after render (needs Termux:X11)
manim -ql -p file.py Scene

04 Live Preview with Termux:X11

Instead of rendering a video file and opening it in VLC, Termux:X11 lets you watch the animation play live on your screen as Manim renders it — just like a real desktop computer.

ℹ️
Make sure you already have the Termux:X11 APK installed on your tablet before starting. Download app-arm64-v8a-debug.apk from github.com/termux/termux-x11/releases

Step 1 — Install X11 Package Inside Termux

Run this in Termux (not inside Ubuntu):

Termux 
pkg install x11-repo -y
pkg install termux-x11-nightly -y

Step 2 — Open the Termux:X11 App

  • Open the Termux:X11 app on your tablet. You will see a black screen — this is normal. It is waiting for a connection.
  • Leave it open in the background and go back to Termux.

Step 3 — Login to Ubuntu with Shared Temp

This time you must login to Ubuntu with an extra flag --shared-tmp — without this, X11 will not connect.

Termux 
proot-distro login ubuntu --shared-tmp

Step 4 — Install XFCE Desktop (First Time Only)

XFCE is a lightweight desktop environment. You only need to install this once.

Ubuntu 
apt install -y xfce4 xfce4-terminal dbus-x11

Step 5 — Start the X11 Session

Ubuntu 
termux-x11 :1 -xstartup "dbus-launch --exit-with-session xfce4-session" &

Now switch to the Termux:X11 app — you should see the XFCE desktop appear. Switch back to Termux to continue.

⚠️
If you see a black screen with only a cursor, go back to Ubuntu and add the -legacy-drawing flag:
termux-x11 :1 -legacy-drawing -xstartup "dbus-launch --exit-with-session xfce4-session" &

Step 6 — Set Display & Activate Manim

Ubuntu 
export DISPLAY=:1
cd ~/manim-projects
source manim-env/bin/activate

Step 7 — Render with Live Preview

Add the -p flag to your render command. This opens the animation live in Termux:X11 as soon as it finishes rendering.

Ubuntu

Switch to the Termux:X11 app — your animation will play automatically.

Step 8 — Stopping X11

When done, exit the X11 session cleanly:

Ubuntu 
pkill -f termux-x11

06 Writing a Manim Code

This is your reference sheet for actually writing scenes — the boilerplate every file needs, plus every common building block: shapes, fill, color, transforms, text, positioning, and 3D. Everything below is click-and-search: scan the sub-headings, jump to whatever you need.

The Boilerplate (Every Scene Needs This)

This is the skeleton of every Manim file you will ever write. Practice typing this out from memory until it's automatic.

Python — the skeleton 
from manim import *

class MyScene(Scene):
    def construct(self):
        # everything happens in here
        # 1. create objects
        # 2. self.play(...) to animate them
        # 3. self.wait(...) to pause
        pass
  • from manim import * — always the first line. Gives you every shape, color, and animation.
  • class MyScene(Scene) — every scene is a class. The name (MyScene) is what you type on the command line to render it.
  • def construct(self): — the only method you write. Manim calls this automatically — everything you want to happen goes inside it.
  • self.play(...) — runs an animation. Nothing appears on screen until it's wrapped in self.play().
  • self.wait(n) — pauses for n seconds. Without this at the end, the video cuts off instantly.
ℹ️
Render this with manim -ql filename.py MyScene — the class name at the end must match exactly (case-sensitive).

Minimal Working Example

Python — smallest real scene 
from manim import *

class MyScene(Scene):
    def construct(self):
        circle = Circle()
        self.play(Create(circle))
        self.wait(1)

Basic Shapes — How to Add Them

Every shape is one line to create, then wrap it in self.play(Create(...)) to animate it onto the screen.

Python — circle, square, triangle, and more 
# Circle
circle = Circle(radius=2, color=BLUE)
self.play(Create(circle))

# Square
square = Square(side_length=2, color=GREEN)
self.play(Create(square))

# Triangle
triangle = Triangle(color=RED)
self.play(Create(triangle))

# Rectangle
rect = Rectangle(width=4, height=2, color=YELLOW)
self.play(Create(rect))

# Line
line = Line(start=LEFT*2, end=RIGHT*2, color=WHITE)
self.play(Create(line))

# Dot (a point)
dot = Dot(point=ORIGIN, color=PINK)
self.play(Create(dot))

# Arrow
arrow = Arrow(start=LEFT, end=RIGHT, color=ORANGE)
self.play(Create(arrow))

# Polygon (any number of custom points)
polygon = Polygon(
    [-1,-1,0], [1,-1,0], [1,1,0], [-1,1,0],
    color=PURPLE
)
self.play(Create(polygon))

# Ellipse
ellipse = Ellipse(width=4, height=2, color=TEAL)
self.play(Create(ellipse))

# Star
star = Star(n=5, outer_radius=2, color=GOLD)
self.play(Create(star))

Fill Color — Filling a Shape with Color

Creating a shape only draws its outline. To fill the inside, set fill_color and fill_opacity (0 = invisible, 1 = fully solid).

Python — fill a shape 
# Method 1 — set when creating
circle = Circle(
    color=BLUE,
    fill_color=BLUE,
    fill_opacity=0.8
)
self.play(Create(circle))

# Method 2 — .set_fill() after creating
square = Square(color=GREEN)
square.set_fill(GREEN, opacity=0.6)
self.play(Create(square))

# Animate the fill appearing (fade in the color)
triangle = Triangle(color=RED)
self.play(Create(triangle))
self.play(triangle.animate.set_fill(RED, opacity=1))

# Different outline color vs fill color
star = Star(color=WHITE, fill_color=YELLOW, fill_opacity=1)
self.play(Create(star))

Colors — Solid & Mixed

Manim ships built-in color constants, but you can also mix your own using hex codes or by blending two colors together.

Python — built-in colors 
# Built-in named colors
RED, BLUE, GREEN, YELLOW, ORANGE, PURPLE, PINK,
WHITE, BLACK, GRAY, GOLD, TEAL, MAROON

# Shades — add _A through _E (A=lightest, E=darkest)
BLUE_A   # very light blue
BLUE_E   # very dark blue
RED_C    # medium red (same as RED)
Python — custom hex & mixed colors 
# Custom hex color — use any color you want
custom = Circle(color="#ff6b9d", fill_color="#ff6b9d", fill_opacity=1)

# Mix two colors together (average of the two)
mixed_color = average_color(RED, BLUE)     # purple-ish
shape = Square(color=mixed_color, fill_color=mixed_color, fill_opacity=1)

# Gradient fill — blends smoothly between two colors
gradient_shape = Circle(
    fill_opacity=1,
    color=WHITE
)
gradient_shape.set_color(color=[BLUE, GREEN])   # gradient across the shape

# Interpolate between colors by a fraction (0 to 1)
half_mix = interpolate_color(RED, YELLOW, 0.5)  # halfway between red & yellow

Color Library — Every Built-in Color Name

The full list of built-in color constants, grouped by family. Every color below has 5 shade levels — add _A (lightest) through _E (darkest) to the name, e.g. PURPLE_A, PURPLE_E. Using the plain name (no suffix) gives you the default middle shade (same as _C).

Python — reds, pinks, maroons 
# Red family
RED_A, RED_B, RED_C, RED_D, RED_E, RED   # RED = RED_C

# Maroon family (deep red)
MAROON_A, MAROON_B, MAROON_C, MAROON_D, MAROON_E, MAROON

# Pink family
PINK, LIGHT_PINK

# Orange family
ORANGE, LIGHT_BROWN, DARK_BROWN

# Yellow family
YELLOW_A, YELLOW_B, YELLOW_C, YELLOW_D, YELLOW_E, YELLOW

# Gold family
GOLD_A, GOLD_B, GOLD_C, GOLD_D, GOLD_E, GOLD
Python — greens & teals 
# Green family
GREEN_A, GREEN_B, GREEN_C, GREEN_D, GREEN_E, GREEN

# Teal family
TEAL_A, TEAL_B, TEAL_C, TEAL_D, TEAL_E, TEAL
Python — blues & purples 
# Blue family
BLUE_A, BLUE_B, BLUE_C, BLUE_D, BLUE_E, BLUE

# Light blue / sky blue
LIGHT_BLUE

# Purple family
PURPLE_A, PURPLE_B, PURPLE_C, PURPLE_D, PURPLE_E, PURPLE
Python — grays, black, white 
# Gray family (also spelled GREY_*, both work)
GRAY_A, GRAY_B, GRAY_C, GRAY_D, GRAY_E, GRAY

# Pure black & white

# As the outline/stroke color
circle = Circle(color=BLUE_D)

# For text
text = Text("Hello", color=TEAL_E)

# For a MathTex formula

# Changing color later with animation
self.play(circle.animate.set_color(MAROON_C))
ℹ️
Full family list at a glance: RED, MAROON, PINK, ORANGE, YELLOW, GOLD, GREEN, TEAL, BLUE, LIGHT_BLUE, PURPLE, GRAY/GREY, WHITE, BLACK. Most support _A–_E shades. You can always fall back to a custom hex string like "#ff6b9d" for any color not in this list — see the custom hex block above.

Text — Writing & Coloring It

Python — text basics 
# Plain text
text = Text("Hello Manim", font_size=48, color=WHITE)
self.play(Write(text))

# Math text (LaTeX) — for equations
formula = MathTex(r"E = mc^2", font_size=60, color=YELLOW)
self.play(Write(formula))

# Colored text — whole string
colored = Text("Colored Text", color=BLUE)

# Color only part of the text (by substring)
partial = Text("Red and Blue")
partial[0:3].set_color(RED)     # colors just "Red"
partial[8:12].set_color(BLUE)   # colors just "Blue"

# Change color with animation (smooth transition)
self.play(text.animate.set_color(RED))

# Bold / italic (Text uses standard args)
bold_text = Text("Bold", weight=BOLD)
italic_text = Text("Italic", slant=ITALIC)

Math Symbols & Formulas — Integrals, Summation, Limits, Derivatives, nCr

All of these go inside MathTex(r"...") — the r before the quotes matters (raw string, so backslashes work). This is plain LaTeX math syntax. Write the whole formula as one string, or split it into multiple pieces inside { } so you can color or animate parts separately.

Python — nCr, nPr, and factorials 
# nCr — combinations, "n choose r"
ncr = MathTex(r"^{n}C_{r} = \frac{n!}{r!(n-r)!}", font_size=60)
self.play(Write(ncr))

# nCr — binomial coefficient notation (the big round-bracket style)
ncr_binom = MathTex(r"\binom{n}{r} = \frac{n!}{r!(n-r)!}", font_size=60)

# nPr — permutations
npr = MathTex(r"^{n}P_{r} = \frac{n!}{(n-r)!}", font_size=60)

# Factorial
factorial = MathTex(r"n!", font_size=60)
Python — integration sign (indefinite & definite) 
# Indefinite integral — plain integral sign
integral = MathTex(r"\int x^2 \, dx", font_size=60)
self.play(Write(integral))

# Definite integral — limits go in _{lower}^{upper} right after \int
definite_integral = MathTex(r"\int_{0}^{1} x^2 \, dx = \frac{1}{3}", font_size=60)
self.play(Write(definite_integral))

# Double integral
double_integral = MathTex(r"\iint_{D} f(x,y) \, dA", font_size=60)

# Triple integral
triple_integral = MathTex(r"\iiint_{V} f(x,y,z) \, dV", font_size=60)

# Closed line/surface integral (loop through the sign)
closed_integral = MathTex(r"\oint_{C} \vec{F} \cdot d\vec{r}", font_size=60)
Python — summation sign (with limits) 
# Summation — \sum, limits again go in _{lower}^{upper}
summation = MathTex(r"\sum_{i=1}^{n} i = \frac{n(n+1)}{2}", font_size=60)
self.play(Write(summation))

# Summation to infinity
infinite_sum = MathTex(r"\sum_{n=0}^{\infty} \frac{1}{n!} = e", font_size=60)

# Product sign (big pi) — same limit syntax as summation
product = MathTex(r"\prod_{i=1}^{n} i = n!", font_size=60)
Python — limit sign 
# Limit — \lim with the approach value under it via \to
limit = MathTex(r"\lim_{x \to 0} \frac{\sin x}{x} = 1", font_size=60)

# Limit going to infinity
limit_inf = MathTex(r"\lim_{x \to \infty} \frac{1}{x} = 0", font_size=60)

# One-sided limits — add ^+ or ^- to the approach value
limit_right = MathTex(r"\lim_{x \to 0^{+}} f(x)", font_size=60)
limit_left = MathTex(r"\lim_{x \to 0^{-}} f(x)", font_size=60)
Python — derivatives (regular, partial, higher order) 
# Derivative — Leibniz notation (d/dx form)
derivative = MathTex(r"\frac{d}{dx} x^2 = 2x", font_size=60)
self.play(Write(derivative))

# Derivative of a function y — dy/dx
dy_dx = MathTex(r"\frac{dy}{dx}", font_size=60)

prime = MathTex(r"f'(x) = 2x \quad f''(x) = 2", font_size=60)

second_derivative = MathTex(r"\frac{d^2y}{dx^2}", font_size=60)

# Partial derivative — use \partial instead of d
partial_derivative = MathTex(r"\frac{\partial f}{\partial x}", font_size=60)

ℹ️
Pattern for limits everywhere in LaTeX: the symbol comes first (\int, \sum, \prod, \lim), then _{ } for the lower/starting value, then ^{ } for the upper value (integrals and sums use both; \lim only uses _{ } with \to inside it). \, just adds a small space (used before dx). Always wrap the whole thing in a raw string: MathTex(r"...").

These formulas need a full LaTeX install to render (see Manual Installation above, texlive-latex-extra). If a symbol doesn't show up or you get a "latex not found" / compile error, check the Troubleshooting table further up this guide.

Transform — Morphing Shapes & Text

Transform smoothly morphs one object into another. ReplacementTransform does the same but fully replaces the original object (better when the two are very different shapes).

Python — transforming shapes 
# Transform a circle into a square
circle = Circle(color=BLUE)
square = Square(color=GREEN)
self.play(Create(circle))
self.play(Transform(circle, square))
self.wait(1)

# ReplacementTransform — cleaner for very different shapes
triangle = Triangle(color=RED)
star = Star(color=YELLOW)
self.play(Create(triangle))
self.play(ReplacementTransform(triangle, star))

# Transform text into other text
text1 = Text("Before")
text2 = Text("After")
self.play(Write(text1))
self.play(Transform(text1, text2))

# Transform a formula into another formula (great for step-by-step math)
eq1 = MathTex(r"x + 2 = 5")
eq2 = MathTex(r"x = 3")
self.play(Write(eq1))
self.play(TransformMatchingTex(eq1, eq2))  # matches similar symbols

Positioning — Moving to Edges & Corners

Every object can be moved with .to_edge(), .to_corner(), .shift(), or .move_to().

Python — edges & corners 
# To an edge
shape.to_edge(UP)               # top center
shape.to_edge(DOWN)             # bottom center
shape.to_edge(LEFT)             # middle left
shape.to_edge(RIGHT)            # middle right

# To a corner
shape.to_corner(UP + LEFT)      # top-left
shape.to_corner(UP + RIGHT)     # top-right
shape.to_corner(DOWN + LEFT)    # bottom-left
shape.to_corner(DOWN + RIGHT)   # bottom-right

# Shift relative to current position
shape.shift(UP * 2)          # move up by 2 units
shape.shift(DOWN * 1)         # move down by 1 unit
shape.shift(LEFT * 3)         # move left by 3 units
shape.shift(RIGHT + UP)      # move diagonally (right + up)

# Move to an exact coordinate
shape.move_to(ORIGIN)        # dead center
shape.move_to([2, 1, 0])     # x=2, y=1

# Position relative to another object
label.next_to(circle, UP)          # above the circle
label.next_to(circle, DOWN, buff=0.5)  # below, with gap
label.next_to(circle, RIGHT)       # to the right of it

# Animate the move (instead of instant jump)
self.play(shape.animate.to_edge(UP))
self.play(shape.animate.shift(RIGHT * 2))
🧭
Direction cheat sheet: UP, DOWN, LEFT, RIGHT are built in. Combine them for diagonals: UP+LEFT = top-left, DOWN+RIGHT = bottom-right, etc.
Python — worked example: move a title from center to top 
# Create text in the center (default position) and show it
text1 = Text("Integral")
self.play(Create(text1))
self.wait(1)

# Animate that same text sliding up to the top-center edge
self.play(text1.animate.to_edge(UP))

.shift() — Full Guide (What It Is, When to Use It)

.shift() moves an object relative to where it already is — it adds an offset to the current position. This is different from .move_to(), which sends the object to an exact, absolute coordinate no matter where it started. Use .shift() whenever you're thinking "move it a bit more from here," and use .move_to() when you're thinking "put it exactly at this spot."

Python — basic shift directions 
# The four basic directions — each is a unit vector you scale with *
shape.shift(UP)                 # up by 1 unit (default)
shape.shift(UP * 2)             # up by 2 units
shape.shift(DOWN * 1.5)         # down by 1.5 units
shape.shift(LEFT * 3)           # left by 3 units
shape.shift(RIGHT * 0.5)        # right by half a unit

# Negative numbers flip the direction (same as the opposite constant)
shape.shift(UP * -2)            # same as shift(DOWN * 2)
Python — diagonal & combined shifts 
# Add two directions together for a diagonal move
shape.shift(RIGHT + UP)              # diagonally up-right by 1 unit each
shape.shift(RIGHT * 2 + UP * 1)      # further right than up
shape.shift(LEFT * 2 + DOWN * 2)    # diagonally down-left

# Shift using a raw [x, y, z] vector instead of UP/DOWN/etc.
shape.shift([1.5, -0.5, 0])       # right 1.5, down 0.5

# Shift along the z-axis (only matters in 3D scenes)
shape.shift(OUT * 2)            # toward the camera
shape.shift(IN * 2)             # away from the camera

# Chaining shifts — each one stacks on top of the last
shape.shift(RIGHT * 2).shift(UP * 1)   # same result as shift(RIGHT*2 + UP*1)
Python — animating a shift (not just an instant jump) 
# Instant jump (no animation) — happens immediately, before self.play
shape.shift(UP * 2)

# Animated — wrap with .animate and pass to self.play
self.play(shape.animate.shift(UP * 2))

# Control how long the animation takes
self.play(shape.animate.shift(RIGHT * 3), run_time=2)

# Shift several objects at once in the same animation
self.play(
    circle.animate.shift(LEFT * 2),
    square.animate.shift(RIGHT * 2)
)

# Shift, then shift again — two separate animation beats
self.play(shape.animate.shift(UP * 1))
self.wait(0.5)
self.play(shape.animate.shift(RIGHT * 1))
Python — common real uses of shift 
# Nudge a label off of the shape it's labeling
label = Text("radius").shift(UP * 0.5)

# Slide an object off screen (to make room / clear the scene)
self.play(shape.animate.shift(LEFT * 8))   # moves off the left edge

# Make a copy and shift only the copy (keeps the original in place)
shape_copy = shape.copy().shift(RIGHT * 3)
self.play(Create(shape_copy))

# Shift a whole group of objects together
group = VGroup(circle, square, triangle)
self.play(group.animate.shift(DOWN * 1))

# Small correction after positioning (fine-tune placement)
label.next_to(circle, UP)
label.shift(RIGHT * 0.2)   # nudge it slightly right
ℹ️
shift() vs move_to() vs to_edge(): .shift(v) = "move by this much from where I am now" (relative). .move_to(point) = "go to this exact coordinate" (absolute — ignores current position). .to_edge(direction) / .to_corner(direction) = "snap to this edge/corner of the screen" (also absolute). If you call .shift() twice, the offsets add up; if you call .move_to() twice, only the last call matters.
⚠️
1 unit in Manim is not 1 pixel — by default the visible frame is about 14.2 units wide and 8 units tall. So shift(RIGHT * 8) is roughly enough to push something off the right edge of a normal frame.

Matrices — As a Real Object on Screen

Use Matrix() when you want a matrix as its own object you can move, transform, or animate entry-by-entry (not just static LaTeX text). It takes a plain Python list of lists.

Python — Matrix object 
# Basic matrix — pass a list of rows
matrix = Matrix([[1, 2], [3, 4]])
self.play(Create(matrix))

# Matrix with brackets style (round, square, curly)
round_matrix = Matrix([[1, 0], [0, 1]], left_bracket="(", right_bracket=")")

# 3x3 matrix
matrix3 = Matrix([[1, 2, 3], [4, 5, 6], [7, 8, 9]])

# Color a single entry — get_entries() returns them in reading order
matrix.get_entries()[0].set_color(YELLOW)   # colors the "1"

# Add brackets/rows highlight, or write it in with animation
self.play(Write(matrix))

# Matrix multiplication equation — mixing Matrix() with MathTex
eq = MathTex(r"\begin{bmatrix} a & b \\ c & d \end{bmatrix}"
             r"\begin{bmatrix} x \\ y \end{bmatrix} ="
             r"\begin{bmatrix} ax+by \\ cx+dy \end{bmatrix}", font_size=48)
self.play(Write(eq))

2D Graphs — Axes, Plotting Functions, log(x)

Axes() creates an x-y coordinate grid you can plot any function on with axes.plot(...). This is the standard way to draw a graph — including log(x), trig functions, or anything else you can write as a Python lambda.

Python — axes and plotting a function 
from manim import *
import numpy as np

class GraphScene(Scene):
    def construct(self):
        # Build the axes first — set ranges to fit your function
        axes = Axes(
            x_range=[-1, 10, 1],
            y_range=[-3, 3, 1],
            axis_config={"color": WHITE},
            tips=True
        )
        # Optional numeric labels on the axes
        labels = axes.get_axis_labels(x_label="x", y_label="y")
        self.play(Create(axes), Write(labels))

        # Plot log(x) — use x_range on the plot to avoid log(0)
        log_graph = axes.plot(lambda x: np.log(x), x_range=[0.1, 10], color=YELLOW)
        log_label = MathTex(r"y = \log(x)", color=YELLOW).next_to(log_graph, UP)
        self.play(Create(log_graph), Write(log_label))
        self.wait(1)
Python — more functions to plot (swap the lambda) 
# log base 10 instead of natural log
log10_graph = axes.plot(lambda x: np.log10(x), x_range=[0.1, 10], color=ORANGE)

# Parabola
parabola = axes.plot(lambda x: x**2, color=BLUE)

# Sine wave
sine_graph = axes.plot(lambda x: np.sin(x), color=GREEN)

# Exponential
exp_graph = axes.plot(lambda x: np.exp(x), x_range=[-2, 2], color=PURPLE)

# 1/x (has an asymptote — split into two plots to avoid the gap being joined)
inv_graph_pos = axes.plot(lambda x: 1/x, x_range=[0.1, 10], color=RED)
inv_graph_neg = axes.plot(lambda x: 1/x, x_range=[-10, -0.1], color=RED)

# Shade the area under a curve (e.g. for definite integrals)
area = axes.get_area(parabola, x_range=[0, 2], color=BLUE, opacity=0.4)
self.play(FadeIn(area))

# A dot that traces along a graph
dot = Dot(color=YELLOW).move_to(axes.i2gp(0, parabola))
self.play(MoveAlongPath(dot, parabola), run_time=3)
ℹ️
Always give log/1/x plots an x_range starting just above 0 (like 0.1) — plugging in x = 0 is undefined and will error or break the graph.

from manim import *
import numpy as np

class ThreeDGraphScene(ThreeDScene):
    def construct(self):
        self.set_camera_orientation(phi=75 * DEGREES, theta=30 * DEGREES)

        axes = ThreeDAxes(
            x_range=[-4, 4, 1],
            y_range=[-4, 4, 1],
            z_range=[-4, 4, 1]

        self.play(Create(axes))

            t_range=[0, 4 * PI],
            color=YELLOW
        )
        self.play(Create(helix))

        # 3D surface plot — z = f(x, y), e.g. a paraboloid z = x^2 + y^2
        paraboloid = Surface(
            lambda u, v: axes.c2p(u, v, (u**2 + v**2) / 4),
            u_range=[-2, 2],
            v_range=[-2, 2],
            fill_color=BLUE,
            fill_opacity=0.7,
            checkerboard_colors=[BLUE_D, BLUE_E]  # optional grid look
        )
        self.play(Create(paraboloid))
        self.wait(2)

Animation Library — Every Animation You'll Use, Grouped by Purpose

Every animation in Manim is a wrapper you pass into self.play(...). This is the full toolkit, grouped by what you're trying to do: bring something onto screen, take it off, morph one thing into another, move it, or draw attention to it.

Python — bringing objects ONTO screen 
# Create — draws the outline/stroke of a shape (most common)
self.play(Create(circle))

# Write — for text and MathTex, writes it stroke by stroke like handwriting
self.play(Write(text))
self.play(Write(formula))

# FadeIn — simply fades in from invisible to visible
self.play(FadeIn(shape))

# FadeIn from a direction — fades in while sliding from that side
self.play(FadeIn(shape, shift=UP))
self.play(FadeIn(shape, shift=RIGHT * 2))

# GrowFromCenter — scales up from a single point in the middle
self.play(GrowFromCenter(shape))

# GrowFromEdge / GrowFromPoint — grows from a specific edge or coordinate
self.play(GrowFromEdge(shape, LEFT))
self.play(GrowFromPoint(shape, ORIGIN))

# GrowArrow — arrow-specific grow-in animation
self.play(GrowArrow(arrow))

# DrawBorderThenFill — draws the outline first, then fills it in
self.play(DrawBorderThenFill(shape))

# SpinInFromNothing — spins in while growing from nothing
self.play(SpinInFromNothing(shape))
Python — taking objects OFF screen / removing 
# FadeOut — simply fades to invisible
self.play(FadeOut(shape))

# FadeOut in a direction — fades while sliding that way
self.play(FadeOut(shape, shift=DOWN))

# Uncreate — reverse of Create, un-draws the outline
self.play(Uncreate(shape))

# ShrinkToCenter — shrinks down to a point and disappears
self.play(ShrinkToCenter(shape))

# self.remove() — instantly removes with NO animation (use outside self.play)
self.remove(shape)

# Clear everything on screen at once
self.play(*[FadeOut(m) for m in self.mobjects])
Python — Transform & ReplacementTransform (morphing A into B) 
# Transform — morphs shape A to look like shape B, but A stays the object in the scene
# (using A again later still refers to the same mobject, now shaped like B)
circle = Circle(color=BLUE)
square = Square(color=GREEN)
self.play(Create(circle))
self.play(Transform(circle, square))

# ReplacementTransform — morphs A into B, then B fully replaces A in the scene
# (cleaner when the two shapes are very different, e.g. circle -> star)
triangle = Triangle(color=RED)
star = Star(color=YELLOW)
self.play(Create(triangle))
self.play(ReplacementTransform(triangle, star))

# TransformMatchingTex — morphs one formula into another, matching identical symbols
# so shared parts glide into place instead of the whole thing dissolving
eq1 = MathTex(r"x + 2 = 5")
eq2 = MathTex(r"x = 3")
self.play(Write(eq1))
self.play(TransformMatchingTex(eq1, eq2))

# TransformMatchingShapes — same idea but for general shapes/VGroups, not just Tex
self.play(TransformMatchingShapes(triangle, star))

# FadeTransform — crossfades between the two objects (fade out A while fading in B)
self.play(FadeTransform(circle, square))

# CounterclockwiseTransform / ClockwiseTransform — like Transform but forces
# the morph to visibly rotate in that direction as it happens
self.play(ClockwiseTransform(circle, square))
Python — movement & positioning animations 
# .animate — the general-purpose way to animate ANY property change
self.play(shape.animate.shift(UP * 2))
self.play(shape.animate.move_to(ORIGIN))
self.play(shape.animate.scale(2))          # scale up 2x
self.play(shape.animate.scale(0.5))        # scale down to half
self.play(shape.animate.rotate(PI / 4))    # rotate 45°
self.play(shape.animate.set_color(RED))
self.play(shape.animate.to_edge(UP))

# MoveToTarget — set a target state first, then animate toward it
shape.generate_target()
shape.target.shift(RIGHT * 3)
shape.target.set_color(YELLOW)
self.play(MoveToTarget(shape))

# MoveAlongPath — animate an object sliding along a curve/graph
self.play(MoveAlongPath(dot, path))

# Rotate — dedicated rotate animation (alternative to .animate.rotate)
self.play(Rotate(shape, angle=PI, about_point=ORIGIN))
Python — emphasis & attention (highlighting without changing the object) 
# Indicate — briefly grows and changes color, then returns to normal
self.play(Indicate(shape))

# Circumscribe — draws a temporary highlight box/circle around it
self.play(Circumscribe(shape))
self.play(Circumscribe(shape, Circle))   # circle instead of the default rectangle

# Flash — a quick burst of lines radiating from a point
self.play(Flash(dot))

# Wiggle — a small shake/wiggle to draw the eye
self.play(Wiggle(shape))

# FocusOn — dims everything else, spotlighting this object
self.play(FocusOn(shape))

# ApplyWave — a ripple/wave distortion passes through the object
self.play(ApplyWave(shape))
Python — sequencing: together, one-after-another, staggered 
# Play multiple animations at the same time (simultaneously)
self.play(Create(circle), Write(text))

# Play animations one after another — just call self.play() again
self.play(Create(circle))
self.play(Write(text), run_time=1.5)

# AnimationGroup — bundles several animations, each with its own delay offset
self.play(AnimationGroup(
    Create(circle),
    Write(text),
    lag_ratio=0.5   # text starts halfway through the circle's animation
))

# LaggedStart — plays a list of animations with a staggered start (nice for lists/groups)
self.play(LaggedStart(
    FadeIn(item1), FadeIn(item2), FadeIn(item3),
    lag_ratio=0.3
))

# Succession — plays animations strictly one after another in a single self.play call
self.play(Succession(Create(circle), Write(text)))
ℹ️
Which "transform" do I use? Plain Transform(A, B) when you'll keep referring to A afterward (it now looks like B). ReplacementTransform(A, B) when B is the object you'll use going forward and the shapes are very different. TransformMatchingTex for step-by-step equation edits (keeps matching symbols steady). FadeTransform when you just want a smooth crossfade rather than a literal morph.
💾
Saving your render: Manim saves automatically — every self.play() is baked into the output video file when you run manim -ql file.py SceneName. There's no separate "save" step; the finished .mp4 lands in media/videos/.../ (see Step 5 — Find & Copy the Output Video above). To render a fresh version after edits, just re-run the same render command — Manim overwrites/creates a new file each time.

07 Install VS Code on Android (proot-distro way)

This uses code-server's official install script instead of npm — skips all the argon2/node-gyp native build headaches entirely.

Termux — enter Ubuntu 
proot-distro login ubuntu
Ubuntu — update & install curl 
apt update
apt install -y curl
Ubuntu — run the code-server install script 
curl -fsSL https://code-server.dev/install.sh | sh

If it installs standalone (not via a package manager), add it to your PATH:

Ubuntu — add code-server to PATH 
export PATH="$HOME/.local/bin:$PATH"
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
Ubuntu — start it 
code-server

Then, from a browser on the same device, open http://localhost:8080.
